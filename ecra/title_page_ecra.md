## Data availability

The code and replication data for this article are available at https://github.com/Nsokol44/zip-demand-model. Input data are the American Community Survey (ACS) 2023 5-year estimates, the ZIP Code Business Patterns (ZBP) for 2022 and 2019, and the Internal Revenue Service Statistics of Income (IRS SOI) ZIP Code data for tax year 2022, all public. The analysis uses a fixed random seed (20261013) and runs end-to-end from the deposited code.
