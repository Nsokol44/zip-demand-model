# ECRA strengthening — repository notes

This folder holds the code and machine-readable results of the ECRA
strengthening program (Tests A–D plus the Bayesian arm of Test A), run
2026-10-26. The narrative record is in `../ECRA_COMPLIANCE.md`, the design in
`../DESIGN_NOTE_STRENGTHENING_2026-10-26.md`, and the per-test memos in
`../MEMO_TEST_*_2026-10-26.md`.

## Contents

- `code/` — the five strengthening analysis scripts
  (`s2a_econ.py`, `s2a_bayes.py`, `s2b_aml.py`, `s2c_wave.py`,
  `s2d_fractions.py`). They read the project's data and the Tier 2 fit store
  from the parent project tree (`../../code/` and `../../results/` relative to
  the manuscript build) and write the JSON results in `results/`.
- `results/` — strict-JSON outputs for Tests A–D, the completed Bayesian arm
  (`test_a_bayes.json`, all 24 draws), the Bayesian verdict computations
  (`test_a_bayes_verdicts.json`), the integration manifest recording the
  provenance of draws r10–r23, run by the author himself and returned by upload
  (`INTEGRATION_MANIFEST_BAYES_2026-10-26.json`), and the run logs.

## Not in the GitHub copy

- `results/test_a_predictions.csv` (~21 MB per-draw prediction file) exceeds
  the snapshot push size limit. It is regenerated by `code/s2a_econ.py`;
  its summaries are in `results/test_a_econ.json` and
  `results/test_a_bayes.json`.
- Binary fit artifacts (per-draw `.npz` arrays and grading files in the
  project's `results/fits/` and `results/predictions/` stores) are not
  mirrored here; the JSON summaries in `results/` fully report them, and the
  integration manifest records names, sizes, and SHA-256 hashes for the
  Bayesian draws.
- Formatted manuscript files (DOCX/PDF) and figures are submission-package
  artifacts; the manuscript sources are the `.md` files one level up.
- One-off editorial stage scripts used to apply the strengthening edits to
  the manuscript (`edit_stage*.py` in the local build) are retained locally;
  the resulting manuscript sources are included, so the end state is fully
  represented.
